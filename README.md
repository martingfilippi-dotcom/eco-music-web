## Política de mantenimiento

No borrar ni archivar este repositorio todavía. Antes de hacerlo, revisar tráfico, enlaces externos, historial y cualquier otro consumidor de sus recursos. Los cambios de contenido se hacen en los repositorios vigentes, no aquí salvo que se decida expresamente mantener el legado.
